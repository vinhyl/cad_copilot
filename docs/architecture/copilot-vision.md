以下为设想原文（未改动，仅格式转换）。

---

本方案旨在打造一套**面向非专业/小白用户**的 Web 端 AI 交互式 CAD/CAM 系统。系统以"自然语言意图驱动"为核心，通过 AI Agent 桥接工业级几何数据（STEP）与工程真理图纸（DWG），使用户无需具备复杂 CAD 软件操作能力，即可在 Web 端完成模型的**可视化查看、智能咨询、精准修改、物理计算与设计审查**。

---

## 1. 系统定位与核心架构设计

系统采用 **"轻 Web 前端 + 本地重计算后端 + 工具调配型 AI Agent"** 的分层架构，核心理念为 **"几何与位置解耦，数据与语义融合"**。

```text
[Web 浏览器 (轻量前端)]
  ├── Three.js (3D 模型/爆炸图/多级对比渲染)
  └── Canvas / SVG (2D DWG 图纸交互渲染)
         ▲
         │ (WebSocket / HTTP 本地双向通信)
         ▼
[AI Agent 中枢 (Codex / WorkBuddy / FastAPI)]
  ├── 自然语言意图解析 & 模糊指令降维
  ├── 智能工具调度 (Tool Calling)
  └── 增量版本与缓存管理器 (Delta Version Manager)
         ▲
         ├── [几何引擎] OCP / build123d (STEP 解析/布尔运算/干涉检查)
         ├── [图纸引擎] ezdxf + ODA Converter (DWG/DXF 文本与轮廓解析)
         ├── [仿真求解] FreeCAD Headless (轻量 FEA 有限元/物理计算)
         └── [离线渲染] Blender Headless (光线追踪渲染/动画导出)

```

## 2. 核心功能模块详细说明

### 模块一：3D/2D 视口双重预览与联动交互

> ⚠ 已修订（ADR-0002 D4）：特征级双向高亮同步移出范围，降级为直观对照
> （分栏 + 同步视角 + 零件级高亮 + 人工确认一次永久记忆）。

* **3D/2D 视口渲染**：Web 前端同时提供 3D 空间模型视图与 2D 工程图纸（DWG 转换为矢量 SVG/Canvas）视图。
* **双向高亮同步 (Cross-Highlighting)**：在 3D 视口中点击某个零件或几何特征，2D 图纸视图自动平移/缩放并高亮对应的标注或零件框；在 2D DWG 上点击序号或尺寸，3D 零件同步高亮指示。
* **多模态涂鸦圈选**：允许用户在 3D 或 2D 视口直接使用鼠标画圈或拉框，配合语音/文本向 AI 提问（例如："圈出来的这个凸起是做什么用的？"）。

### 模块二：数据解耦与装配体层级节点控制

*  Template + Matrix 数据解耦：
* **零件模板库**：后端将装配体 STEP 解构为唯一的单个子零件 `.gltf` / `.step` 几何模板。
* **空间矩阵**：提取各零件在装配体中的 4×4 齐次变换矩阵保存为 JSON。
* **GPU 实例化渲染**：Web 端同规格零件（如螺栓）仅需加载 1 次几何体，通过矩阵复制 100 个实例，极致提升响应速度。


* **层级结构列表与分层爆炸图**：
* **装配树 UI**：提供清晰的父子装配节点树，支持单独隐藏、隔离或高亮某一子装配体。
* **多层级自动爆炸图**：后端计算各子装配体的包围盒（Bounding Box）与空间质心，自动生成沿轴向/向外的平移向量。前端提供 `爆炸比例 (Explosion Ratio)` 拖动条，可按照"整机层级"或"子装配体层级"进行分层爆炸演示。

#### 视图操作集（2026-08-19 补充，Phase B 范围）

> 边界原则（源自 ADR-0002 D3 讨论）：**视图状态 ≠ 数据状态**。以下操作全部为
> 前端场景图状态，零后端往返、不进版本树；"真的改装配位置"是写操作，走完整
> ③ 类流程（双轨写 → 干涉守门 → DWG 更新 → 原子提交）。

| 操作 | 说明 | 复位方式 |
|---|---|---|
| 隐藏 / 显示 | 按节点（零件或子装配体）切 visibility | 树上节点开关 |
| 隔离 | 只显示选中节点，其余隐藏 | 一键恢复全部 |
| 透明 / 鬼影（X 光） | 临时材质覆盖看内部结构 | 一键恢复 |
| 零件 / 子装配体临时拖拽 | 实例矩阵 × 临时增量，默认**不落盘** | 按粒度复位（见下） |
| 自定义爆炸布局 | 临时拖拽的布局可保存复用（仍属视图配置） | 切回自动爆炸 |
| 剖切面 | 前端 clipping plane 截面视图 | 关闭 |
| 相机书签 / 视角复位 | 保存常用视角 | 回默认视角 |

拖拽的双含义须在 UI 上显式区分：**临时挪开**（探索用，上表）vs **提交位置变更**
（写操作）。拖拽默认为临时，落盘需明确的"提交位置变更"动作。

#### 选择层级交互原则（2026-08-19 补充）

拖拽 / 隐藏 / 隔离等操作作用于零件还是子装配体，由**选择层级**决定，且必须在
操作发生前显式确定：

1. **装配树是主锚点**：点哪个节点就选哪个层级——点"轴承组件"选整个子装配体，
   点"内圈"选单个零件；树与 3D 视口选中状态双向同步。
2. **视口点选消歧**：单击默认命中射线最外层叶子零件（所见即所选）；双击或
   快捷键循环升档（零件 → 所属子装配体 → 整机）修正歧义（重叠遮挡场景）。
3. **状态可见性**：零件选中 = 单件轮廓高亮；子装配体选中 = 组高亮 + 包围盒虚线框；
   状态栏常驻当前选择（如 `泵头组件（子装配体，5 个零件）`）；拖拽跟随的
   对象在松手前视觉可确认，Esc 可取消。
4. **复位分层**：`复位零件` / `复位子装配体` / `复位全部临时移动` 三个粒度独立提供；
   装配树节点右键菜单（隐藏 / 隔离 / 复位）作用域即节点层级，天然无歧义。



### 模块三：非专业用户自然语言意图映射

> ⚠ 已修订（ADR-0002 D9）：先跑评测飞轮（基准集 + 批量评测 + 归因迭代），
> 达标后才分级固化交互；先 CLI 无 UI。

* **模糊指令降维**：用户输入大白话（如"把这根轴换个大号的"），AI 自动匹配零件历史规格并弹出标准化选型下拉框（如：推荐 M8/M10 标准件选型）。
* **意图解构与预设方案**：当用户表达抽象需求（如"让这里更结实一点"），AI 自动分析力学结构，生成 2-3 个图形化预设方案供点选（如：方案 A 加厚侧壁 2mm / 方案 B 增加两条加强筋 / 方案 C 更换钛合金材质）。
* **去专业化大白话解说**：屏蔽"B-Rep"、"法线"、"倒角"等专业词汇，将 CAD 警告翻译为易懂的工程因果逻辑（例如："如果把这个凹槽填平，隔壁的连杆转动时会卡死"）。

### 模块四：3D 特征拾取、智能修改与 DFM 校验护栏

* **网页端 3D 特征拾取**：用户可在网页端点选模型的"面、孔、边、凸台"等几何特征，作为 AI 修改的输入上下文。
* **物理干涉实时检测**：AI 执行几何修改后，后台静默调用 OCP 的 `BRepAlgoAPI_Section` 工具。若发现新几何与其他零件发生物理穿透，AI 立即在 3D 视口用红色虚线高亮干涉区域，并询问用户是否自动进行避让切削。
* **实时 DFM（可制造性）与成本预警**：检测无法加工的盲区（如壁厚小于 1mm、CNC 不可达的深狭槽），并联动 BOM 显示成本预估（如："修改后预计重量 +12%，加工成本 +18%"）。
* **多层级 Diff 实时对比**：修改完成后，前端支持"双视口对比"或"半透明叠加对比"，并可自由切换对比视角：`[仅对比该零件]` / `[对比子装配体效果]` / `[对比整机效果]`。

### 模块五：接口锁定保护机制 (Interface Locking)

* **自动识别装配配合区**：系统解析装配关系，自动将与其他零件存在贴合、轴孔配合或螺纹连接的面/孔标记为"锁定的装配接口"。
* **修改安全提示**：当用户尝试编辑被锁定的接口时，系统弹窗二次确认："该区域正在与 [底座] 紧密配合，修改可能导致整机无法装配，确定要解锁修改吗？"。

### 模块六：DWG 数据校准与确定性物理计算

> ⚠ 已修订（ADR-0002 D10）："DWG 为语义真理"仅在导入时成立；系统开始修改
> STEP 后真理方向翻转——双轨修改 + 语义 diff 驱动 DWG 分级更新（T1 标注改值 /
> T2 视图重建 / T3 人工复核）+ 原子版本提交 + staleness 状态机。

* **DWG 语义校准真理**：将 DWG 提取的文本（如 `M10x1.5` 螺纹、H7/g6 公差）作为语义真理，自动修正 STEP 导出的无属性光孔，并生成统一的 `metadata.json`。
* **确定性物理计算工具箱（Tool Calling）**：**严禁 AI 凭空估算物理数值**。所有物理计算均由 AI 调用确切的 Python 后端工具执行：
* **质量 / 重心 / 惯性矩**：调用 OCP `GProp_GProps` 计算精确体积，结合 DWG/BOM 材质密度推算。
* **容器容量**：自动寻找封闭内腔曲面，生成闭合实体并计算容积。
* **力学 / 热学分析**：轻量级需求调用 FreeCAD Headless + CalculiX 静力学求解，向 Web 前端返回彩色的应力云图（Stress Mesh）。
  > 🚧 落地状态（2026-08-20）：`cad_fea.py` 插件框架已实现（探测/降级/缓存/七阶段进度汇报 + `/api/fea/static`）；应力云图为后续增量，当前返回 max 位移 / max von Mises 数值。



### 模块七：AI 智能设计审查（一键体检报告）

> ⚠ 已修订（ADR-0002 D10）：升级为每次版本提交的守门检查（导入时体检 /
> 提交时哨兵双重角色），语义 diff 期望值与实际 DWG 标注值对不上则拒绝提交。

* **一键健康度诊断**：用户导入新项目时，提供"一键审查"按钮。AI 自动扫描整个装配体并生成诊断报告：
1. 识别潜在的静态干涉与装配间隙问题；
2. 标注 STEP 几何与 DWG 图纸规格不一致的差异点；
3. 识别缺乏倒角、存在应力集中的危险结构并给出修改建议。


### 模块八：渲染与运动动画预留

> ⚠ 已修订（ADR-0002 D7）：Blender 为可选插件。
> 🚧 落地状态（2026-08-20）：`cad_render.py` 插件框架已实现（探测/降级/
> 缓存 + 模板 glTF 实例化 + 自动相机取景 + `/api/render`）；Blender 仅作
> 外部依赖 headless 调用（R9 许可边界）。动画导出为后续增量。

* **离线高精度渲染**：基于数据解耦架构，点击"生成效果图"时，后台启动 Blender Headless (`bpy`)，加载 4x4 矩阵与材质库，自动进行 Cycles 4K 离线光轨渲染。
* **运动与拆解动画**：爆炸图或运动轴转向序列仅通过更新矩阵 JSON 实现，Web 前端 Three.js 即可直接实现 60 FPS 的流畅运动演示。

## 3. 本地存储、缓存与增量版本管理 (Delta Versioning)

针对本地运行（结合 Codex / WorkBuddy）的需求，设计如下项目本地工作区结构：

### 工作区目录架构 (`workspace/`）

```text
workspace/
├── raw_inputs/                  # [只读] 原始 STEP 与 DWG 文件
├── cache/                       # [自动生成] Web 端快速加载缓存区
│   ├── tree_structure.json      # 原始装配树与初始 4x4 矩阵
│   ├── dwg_converted.dxf        # ODA 转换后的中间 DXF
│   ├── dwg_view.svg             # 2D 网页交互矢量图
│   └── gltf_library/            # 解耦后的所有子零件初始 glTF
└── versions/                    # [增量时光机] 版本历史节点
    ├── v1.0_original/           # 初始版本元数据
    └── v1.1_add_stiffener/      # 修改节点 1
        ├── modified_part_A.step # 仅保存被修改零件的新 STEP
        ├── modified_part_A.gltf # 仅保存被修改零件的新 glTF
        ├── assembly_matrix.json # 更新后的实例映射/矩阵 JSON
        └── changelog.txt        # AI 自动生成的自然语言修改日志

```

> ⚠ 已修订（ADR-0002 D10）：版本节点升级为"一致性文件族"——含 step/gltf/matrix
> + `metadata.json` + `drawing.dwg` + changelog，原子提交，历史版本 DWG 永不重写；
> 另见 R6（崩溃恢复）、R8（缓存失效键 = 源文件 SHA-256）。

### 缓存与版本机制逻辑

1. **冷启动与二次加载**：首次打开装配体时，Python 后端执行拆解并缓存至 `cache/`；二次打开时 0 秒直接读取 `cache/` 渲染。
2. **增量版本控制 (Delta Storage)**：用户修改某一零件（如零件 A）时，AI 只生成零件 A 的新 `.step` 和 `.gltf` 并存入新的 `versions/v1.x/` 目录；其他未改变的 99 个零件继续复用初始缓存，极大地节省本地磁盘空间。
3. **版本对比与瞬间撤销**：
* **对比**：Three.js 视口同时加载老版本零件（半透明红）与新版本零件（实体绿）重叠显示。
* **撤销**：用户输入"撤销修改"，前端仅需将矩阵与零件指针切回上一个版本的 JSON，无需重算整个装配体。

## 4. 技术栈规范与软硬件配置要求

> ⚠ 已修订（ADR-0002 D2/D5/D6/D7）：FastAPI/FastMCP 为确定性服务层、调度复用
> MCP 生态（不自研 Agent 框架）；DWG/ODA 默认开启 + 探测降级 + 缓存；FreeCAD
> 默认开启但 headless 子进程隔离（主服务永不 `import FreeCAD`）；Blender 可选插件。
> 另见 R9（对外分发时的第三方许可硬约束）。

### 软件技术栈 (Technology Stack)

* **前端 (Web)**：Three.js (3D 渲染/矩阵变换/爆炸图)、Canvas/SVG (2D 交互)、WebSockets (实时通信)。
* **AI 驱动与调度**：Codex / WorkBuddy / Python FastAPI 本地微服务。
* **CAD/CAM 几何内核**：Python `build123d` + `python-ocp` (Open CASCADE)。
* **图纸与文档**：`ezdxf` + `ODA File Converter` (静量 CLI 调用)。
* **扩展工具**：FreeCAD Headless (有限元求解/2D 出图)、Blender Headless (离线渲染)。

### 本地硬件配置要求

| 配置层级 | CPU / 内存 | 显卡 (GPU) | 适用场景 |
| --- | --- | --- | --- |
| **基础运行配置** | 8 核 CPU / 16 GB 内存 | 集成显卡 (Intel Iris Xe / Apple M 系列) | 中小型装配体查看、自然语言修改、2D/3D 联动、干涉检测 |
| **推荐体验配置** | 16 核 CPU / 32 GB 内存 | NVIDIA RTX 3060 / 4060 (8GB 显存) | 大型装配体流畅爆炸图、复杂 FEA 力学仿真、Blender 本地快速渲染 |
